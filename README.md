## Building FS Calling Line

**FS Calling Line** is my primary software project currently under active development.

The project is being developed toward a cross-platform communication experience for **Android, Windows, and iOS**, with calling, call activity, analytics, connectivity, and live transcription as core areas of development.

### Current Android Development

The Android application currently focuses on:

- **Calling:** dial pad, in-call controls, contacts, and call activity
- **Transcription:** live transcript viewing supplied through a paired Windows companion
- **Languages:** English + Dari/Farsi and English + Pashto transcription workflows
- **Connectivity:** QR pairing, Wi-Fi/network connectivity, Bluetooth, and device diagnostics
- **Transcript tools:** search, copy, and TXT/JSON export
- **Call activity:** call history and related activity views

**Current Android version:** `0.7.1-dev`  
**Status:** Development preview

Live transcription requires the matching Windows companion and a configured transcription provider or local model.
