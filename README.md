# Building FS Calling Line

Android calling tools with PC-powered live transcription.

## Featured project

### [FS Calling Line](https://github.com/princeakbari48-spec/FS-Calling-Line)

An Android companion that brings phone controls, call activity, device pairing, and live transcript viewing into one app.

- **Calling:** dial pad, in-call controls, contacts, and call activity.
- **Transcription:** captions supplied by a paired Windows companion, with English + Dari/Farsi and English + Pashto options.
- **Connectivity:** QR pairing, Wi-Fi/network and Bluetooth connections, and device diagnostics.
- **Transcript tools:** search, copy, and TXT/JSON export.

**Current Android version:** 0.7.1-dev · **Status:** development preview

The public repository contains the Android application. Live transcription requires the matching Windows companion and a configured transcription provider or local model.

[Explore the source and setup guide](https://github.com/princeakbari48-spec/FS-Calling-Line#readme)
